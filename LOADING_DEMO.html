🎯 Implementation Details

Automatic HTTP Loading

All API requests automatically show/hide the loading overlay. No setup required!

Counter-Based System

Multiple concurrent requests share one overlay. Smart debouncing prevents flickering.

Manual Control

Use useLoading() hook for complete control over loading state when needed.

Advanced Async Hooks

useAsyncOperation, useMultipleAsyncOperations, useAsyncForm for complex flows.

Dark Mode Ready

Automatic theme detection and color adaptation. Works seamlessly in light/dark modes.

Fully Customizable

Change colors, speeds, particles, logo. All through simple CSS/config edits.
