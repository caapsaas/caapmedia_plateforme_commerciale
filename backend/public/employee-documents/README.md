# Employee Documents Storage

This directory is used for storing uploaded employee documents including:
- Employment contracts
- ID cards / National IDs
- Work permits
- Diplomas and certifications

## File Structure
Files are stored with unique identifiers to prevent filename conflicts:
- Format: {uuid}.{extension}
- Example: 826d4757-005f-46f9-a1f2-6c203732b1d4.jpg

## Cleanup
Old or deleted documents may be removed to free up space.

## Security Note
This directory should be:
1. Properly backed up regularly
2. Restricted to authorized access only
3. Scanned for malware periodically
